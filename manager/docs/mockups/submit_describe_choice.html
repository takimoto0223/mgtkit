1. 更新版を提出するタブ (入力欄をなくし、ボタンだけ)

記入は ZIP を選んだ後のダイアログに移す。タブは「何をすると何が起きるか」の説明と提出ボタンだけになる。

起動
β版の確認と承認
更新版を提出
設定

作業した mgtkit のフォルダを ZIP にして提出すると、自動で検証されます。 エラーなく本体に組み込める状態になるとβ版として発行され、メンバーの確認と承認を経て 正式版になります。マネージャーで取得した版 (version.json 入り) を基に作業してください。

フォルダは丸ごと ZIP にして構いません。取得した版から変更したファイルだけが提出され、 個人設定 (API キーなど)・計算結果 (mgtkit_out)・PDF や実行ファイル (.bat など) コード以外のファイルは自動で除外されます。

ZIP を選んだあとの確認画面で、更新内容の説明を「Claude で自動作成」か「自分で入力」かを選べます。

⬆ ZIP を選んで提出

2. ZIP を選んだ直後の確認ダイアログ (既定 = Claude で自動作成)

既存の確認事項 (件数・提出先) の下に「説明の作り方」を常設。自動作成のままなら記入欄は出ないので、これまでと同じ手数で提出できる。

提出内容の確認

追加 1 件 / 変更 3 件のファイルを提出します。

変更のないファイルは送られません。個人設定 (API キーなど) や計算結果は自動で除外済みです。
