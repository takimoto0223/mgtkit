# 画面モック (見た目確認用・未実装)

ブラウザでそのまま開けます (ダブルクリックで OK)。
アプリ本体には組み込まれていない、見た目の合意用モックです。
実装するときはこのモックを仕様として使ってください
(ファイル冒頭のコメントに実装メモがあります)。

| ファイル | 内容 |
| --- | --- |
| `history_flow.html` | 過去の更新ログの図: 誰がどの版を基に作り、どこで正式版になったかの時系列図 + 一覧。横スクロール・ホバー詳細・現行版の強調入り |
| `history_conflict_note.html` | 更新どうしが重なった (コンフリクトした) 場合の「更新内容」画面: 図の ◆ = AI が自動調整した点、琥珀色の枠 = 調整内容の説明 |

- 図の文法: グレーの本線 = 正式版の列 (白丸 = 版、大きい紺丸 + 橙リング = 現行版)。
  人ごとの色の帯 = 提出された更新 (左端 = 提出日)。ノードから降りる線 = その版から
  派生、本線へ上がる矢印 = 正式版として公開。点線の帯 = 確認中。
- 時間軸は横 (左が過去)、42px/日の等縮尺。初回配布より左には何も描かない。
