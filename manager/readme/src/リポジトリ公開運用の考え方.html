mgtkit のプログラム置き場を「公開」にしていることのリスク整理

2026-10 版 — mgtkit のプログラムは GitHub という保管サービス上の「公開(パブリック)リポジトリ」に置いています。その意味とリスクを 1 枚にまとめました。2026-09 に付けたライセンス (PolyForm Perimeter) を反映しています。

たとえ話: いまは「ガラス張りの工房」

mgtkit の置き場は、いわばガラス張りの工房です。通りがかりの誰でも、中の道具や図面(プログラムや計算ロジック)を自由に見学・撮影(コピー)できます。 ただし、工房に入って作品に手を加えられるのは、鍵(権限)を渡した社内メンバーだけ。しかも完成品の棚(正式版)に置くには「社内 2 名の検印 + 検査機(自動テスト)の合格」が必要で、このルールは工房のシステムが強制します。部外者が改造案を投げ込む(提案する)ことはできますが、検印には一切カウントされず、無視すれば作品には何も影響しません。
さらに入口には「利用規約の看板(ライセンス)」を掲げています。撮影したものを持ち帰って自分で使う・手を加える・人に渡すのは自由。ただしそっくり同じ商売(競合する製品)を始めて他人に提供することだけは禁止、という看板です。

公開のままで残るリスク(=「見られる」ことに尽きる)

① 設計ノウハウの流出【最大の論点・唯一の実質リスク】
断面算定のロジック、基準データ、マニュアル、開発のやり取りの履歴まで全世界に公開されます。ライセンス(PolyForm Perimeter License 1.0.0)で、閲覧・自社での利用・改変・再配布は認めたうえで、mgtkit と競合する製品を他者に提供する目的の利用だけを禁止しています。「見て覚えて自分の仕事に使う」ことは止められず、競合製品への転用も見つけて対処するのは現実的に困難です。これは技術でもライセンスでも防げない「経営判断」の領域です。
② いたずら・乗っ取り → 対策済みでほぼ心配なし
部外者ができるのは「見学」と「提案」まで。作品(正式版)を変更できるのは鍵を持つメンバーだけで、検印(承認)も社内メンバーの分しか数えない仕組みを入れてあります。
③ パスワード類の流出 → 設計で防止済み(ただし猶予ゼロ)
API キー等の秘密情報は工房に持ち込まない設計(各自の PC にのみ保存+提出時の自動除外+自動検査)。ただしガラス張りなので、万一うっかり持ち込むと「即座に」見られる点だけは非公開と違います。

「シャッターを閉める(非公開)」にする場合

非公開にする=シャッターを閉めた工房。見学は完全にできなくなりますが、代わりに——
・入る人全員に入館証を 1 枚ずつ発行する手間が復活(インターン・バイト含む)
・「検印 2 名+検査機」のルールをドアに強制させる装置が有料オプションになる(GitHub Pro: 月 $4 程度。未加入だとルールはアプリ側の運用頼みに)
・入口の看板(ライセンス)はそのまま残ります。外し直す作業はありません

困らない → いまの公開運用+ライセンスがベスト(手間ゼロ・保護も無料で有効)。/ 困る → 「非公開+Pro+招待運用」に切り替え(設定変更 3 手順・プログラム改修は不要。いつでも移行できます)。
