覚えていただきたいのは、これだけです mgtkit_appmanager\stable\mgtkit が、いま動いているアプリです。
機能を追加するときは、デスクトップなど mgtkit_appmanager の外に貼り付けてから直してください。
例) stable\mgtkit を右クリック → コピー → デスクトップに貼り付け → できた mgtkit フォルダの中で作業 → そのフォルダを ZIP にして「更新版を提出」タブから提出。
鍵はかけません かけても外せてしまいますし、鍵の掛け外しに失敗すると更新そのものが止まります。かわりに、 stable\mgtkit に手が入っていたら、更新の前に mgtkit_appmanager\stash\日時\ へ 退避してからお知らせします (複製ではすでにこの仕組みが動いています)。
ただし退避は保険であって、直してよいという意味ではありません。 stable\mgtkit は更新のたびに丸ごと入れ替わる場所なので、作業を続ける場所には向きません。
