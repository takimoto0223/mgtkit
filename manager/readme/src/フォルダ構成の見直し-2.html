切り替えでお願いすること (見込み)

お願いするのは 1 つだけです。新しい setup.bat を もう一度ダブルクリックしてください (5 分程度の見込みです)。あとは マネージャーが引っ越しから後片付けまで自動で行います。

  • お名前・API キー・利用量はそのまま引き継ぎます。入力し直しは不要です。
  • 古いフォルダはご自分で消さないでください。引き継ぎに使います。 済んだあとにマネージャーが自動で片付けます。
  • 計算結果 (mgtkit_out) は今までどおり mgt ファイルと同じ場所です。移動しません。
  • 使い方ガイドに書かれているフォルダの場所 (1・2・4・8 章と付録) は、切り替えにあわせて改訂します。
ご意見のお願い

そもそも、このプログラムの各自の PC 内での置き場は C:\Users\(自分)\ の下でよいでしょうか。 たとえば「C:\mgtkit_appmanager (C ドライブの直下。誰のフォルダでもない場所) の方がよい」など、ご希望があればお知らせください。置き場所は今なら変えられます。
